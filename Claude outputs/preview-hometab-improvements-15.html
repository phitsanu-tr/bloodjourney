3 จุดปรับปรุงหน้าหลัก — เทียบจุดละ 5 แบบ

A) การ์ดเชื่อมไปภารกิจ — B) สีป้ายประเภทในประวัติ — C) ตัวกรองประเภทในประวัติ

A. การ์ดเชื่อมโยงไปภารกิจ

A1. แบนเนอร์บางๆ ใต้การ์ดสรุป
ข้อความสั้น + ลิงก์ "ดูภารกิจ" กินพื้นที่น้อยสุด
🏅 ใกล้ปลดล็อกเข็มทองคำแล้ว อีก 3 ครั้ง ดูภารกิจ →
A2. การ์ดมี progress bar
เห็นความคืบหน้าเป็นภาพ ไม่ใช่แค่ตัวเลข ดึงดูดกว่า
🏅 ภารกิจถัดไป: เข็มทองคำ
15/18 ครั้ง — อีก 3 ครั้ง
A3. ชิปแบบกะทัดรัดต่อท้ายแถวป้ายประเภท
แปะติดกับป้าย "โลหิตรวม/พลาสมา" ในการ์ดสรุปเดิมเลย ไม่เพิ่มการ์ดใหม่
💧 โลหิตรวม 39 💧💧 พลาสมา 3 🏅 15/18
A4. การ์ดพร้อมไอคอนเหรียญ/เข็มกราฟิก
เน้นภาพเหรียญ/เข็มให้รู้สึกเป็นรางวัลจริงจัง เหมาะเป็นการ์ดแยกต่างหาก
🏅
อีก 3 ครั้ง ปลดล็อกเข็มทองคำ
แตะเพื่อดูภารกิจทั้งหมด
A5. ไม่ต้องเพิ่ม (คงหน้าหลักโฟกัสแค่บันทึก/ประวัติ)
อาจดูรกขึ้นถ้าใส่ทุกอย่าง ปล่อยให้แท็บภารกิจทำหน้าที่ของมันแยกไป
— ไม่มีการ์ดเพิ่ม —

B. สีป้ายประเภทในประวัติ

B1. สีพื้นหลังต่างกันตามประเภท (แดงอ่อน / ม่วงอ่อน)
แยกชัดสุดตาแรกเห็น ไม่ต้องอ่านไอคอน/ข้อความ
💧 โลหิตรวม
💧💧 พลาสมา/เกล็ดเลือด
B2. คงสีเดิม แต่เพิ่มแถบสีข้างการ์ด (left border accent)
ละมุนกว่า B1 ไม่เปลี่ยนโทนสีป้าย แค่เพิ่มเส้นบอกประเภทที่ขอบการ์ด
💧 โลหิตรวม
💧💧 พลาสมา/เกล็ดเลือด
B3. วงกลมไอคอนหมายเลขครั้งเปลี่ยนสีตามประเภท
ใช้พื้นที่วงรีหมายเลข "ครั้งที่" ที่มีอยู่แล้วสื่อสีแทน ไม่เพิ่มองค์ประกอบใหม่
B4. จุดสีเล็กๆ หน้าป้าย แทนที่จะเปลี่ยนทั้งป้าย
เพิ่มแค่จุดสี ไม่รบกวนดีไซน์ป้ายเดิมเลย เปลี่ยนแปลงน้อยสุด
💧 โลหิตรวม
💧💧 พลาสมา/เกล็ดเลือด
B5. ไม่ต้องเพิ่มสี (คงไอคอนแยกอย่างเดียวเหมือนเดิม)
ผู้ใช้ส่วนใหญ่ไม่ได้สแกนประวัติถี่ๆ ไอคอนต่างกันอาจเพียงพออยู่แล้ว
💧 โลหิตรวม

C. ตัวกรองประเภทในประวัติ

C1. ชิปกรองแบบ segmented ต่อแถวจากตัวกรองปี
ทั้งหมด / โลหิตรวม / พลาสมา — แตะเปลี่ยนได้ทันที ไม่ต้องเปิดเมนู
ทั้งหมด 💧 โลหิตรวม 💧💧 พลาสมา
C2. เพิ่ม select ประเภท คู่กับ select ปีเดิม
ใช้ UI แบบเดียวกับตัวกรองปีที่มีอยู่แล้ว เข้ากันได้ทันที ไม่ต้องเรียนรู้ใหม่
C3. รวมเป็น select เดียว (ปี + ประเภท)
ประหยัดพื้นที่สุด แต่รายการตัวเลือกจะยาวขึ้นถ้ามีหลายปี
C4. ปุ่มไอคอนตัวกรอง เปิด popover เลือกได้หลายเงื่อนไข
รองรับกรองซ้อนได้มากขึ้นในอนาคต (เช่น สถานที่) แต่ต้องกดเพิ่ม 1 ขั้น
C5. ไม่ต้องเพิ่มตัวกรอง (ใช้ปีอย่างเดียวพอ)
คนส่วนใหญ่มีประวัติไม่เยอะพอจะต้องกรองประเภทซ้อนปี อาจไม่คุ้มความซับซ้อนที่เพิ่ม
— ตัวกรองปีอย่างเดียว —
