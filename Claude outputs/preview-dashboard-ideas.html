ไอเดีย: หน้าแดชบอร์ดเพิ่มอะไรได้อีกบ้าง

ยังไม่ได้แก้โค้ดจริง — เป็นไอเดียระดับแนวคิด 10 อย่างที่อาจเพิ่มในหน้าแดชบอร์ด (ตอนนี้มี: ระยะห่างเฉลี่ย, ปีที่บริจาคมากสุด, ปริมาณสะสม, กราฟรายปี) เลือกอันที่สนใจแล้วค่อยออกแบบ UI จริงต่อได้เลย

1แถบความคืบหน้าสู่เป้าหมายถัดไป

แสดงว่าใกล้ปลดล็อกความสำเร็จ/เหรียญถัดไปแค่ไหน เช่น "อีก 2 ครั้งถึงระดับถัดไป" พร้อมแถบ progress

🏆 นักบริจาคทองแดง → เงิน
2ปฏิทินความสม่ำเสมอ (heatmap)

ตารางสีเข้ม-อ่อนตามเดือนที่มีการบริจาค คล้าย GitHub contribution graph ดูภาพรวมทั้งปีได้ในตาเดียว

3สัดส่วนประเภทการบริจาค

กราฟวงกลม/แท่งเทียบ "โลหิตรวม" กับ "พลาสมา/เกล็ดเลือด" ว่าบริจาคแต่ละแบบไปกี่ครั้ง สัดส่วนเท่าไหร่

◇ โลหิตรวม 4🩸 พลาสมา 2
4เทียบกับปีก่อนหน้า

"ปีนี้บริจาค 3 ครั้ง เทียบปีที่แล้ว 2 ครั้ง (+50%)" ให้เห็นแนวโน้มว่าทำได้ดีขึ้นหรือลดลง

2569: 3 ครั้ง ▲ +1 จากปี 2568
5สถานที่ที่บริจาคบ่อยที่สุด

สรุปอันดับสถานที่/หน่วยรับบริจาคที่ไปบ่อยสุด จากข้อมูลสถานที่ที่เคยกรอกไว้ในแต่ละรายการ

1. ที่ทำงาน (3 ครั้ง)
2. รพ.จุฬาฯ (2 ครั้ง)
