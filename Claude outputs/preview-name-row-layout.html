ตัวอย่าง: จัดวาง ชื่อ / นามสกุล

ยังไม่ได้แก้โค้ดจริง — ทดสอบด้วยชื่อ-นามสกุลยาวปานกลางเพื่อเทียบความอึดอัดของช่อง

แบบ A — คนละแถว (ปัจจุบัน)
แต่ละช่องกว้างเต็ม พิมพ์ชื่อยาวได้สบาย แต่ฟอร์มสูงขึ้น
ใช้แสดงบนการ์ดแชร์ผลงาน หากไม่ใส่จะไม่แสดงชื่อบนการ์ด
แบบ B — แถวเดียวกัน แบ่งครึ่ง 1:1
ประหยัดพื้นที่ แต่ชื่อ-นามสกุลยาวจะถูกบีบ ล้นหรือขึ้นบรรทัดใหม่ในช่อง
ใช้แสดงบนการ์ดแชร์ผลงาน หากไม่ใส่จะไม่แสดงชื่อบนการ์ด
แบบ C — แถวเดียวกัน แบ่งไม่เท่ากัน (ชื่อ 1 : นามสกุล 1.3)
ให้น้ำหนักนามสกุลมากกว่านิดหน่อยเพราะมักยาวกว่าชื่อ ยังประหยัดพื้นที่เหมือนแบบ B แต่บีบน้อยกว่า
